# Next Tech Assistência Técnica

Este repositório reúne a landing page da Next Tech voltada para assistência técnica de smartphones e computadores, além da venda de dispositivos e planos de proteção.

## Como visualizar

Basta abrir o arquivo [`index.html`](index.html) em qualquer navegador moderno. Para obter a melhor experiência, utilize a folha de estilos [`styles.css`](styles.css) e os scripts [`script.js`](script.js) incluídos na mesma pasta.

## Tecnologias e recursos

- HTML semântico com seções para produtos, manutenção, suporte, garantia, diferenciais e contato.
- Layout responsivo inspirado no visual original, com topo escuro, gradiente multicolorido e componentes glassmorphism.
- JavaScript leve para slider de destaques, rolagem suave, botão “voltar ao topo” e respeito ao `prefers-reduced-motion`.
- Tipografia moderna utilizando a fonte [Outfit](https://fonts.google.com/specimen/Outfit).

Sinta-se à vontade para adaptar os conteúdos e estilos conforme a identidade da sua marca.
