# JP Salgados · Landing Page

Este repositório contém uma landing page moderna e responsiva para a JP Salgados.

## Pré-visualização

Abra o arquivo `index.html` diretamente no navegador ou rode um servidor local simples:

```bash
python -m http.server 8000
```

Depois acesse `http://localhost:8000/index.html`.

## Imagens

Para manter a essência do site original, os elementos visuais tentam carregar automaticamente as mesmas fotos já
disponíveis no domínio `jpsalgados.ct.ws`. Caso o servidor utilize nomes de arquivos diferentes, ajuste os atributos
`data-fallbacks` (para imagens diretas) e `data-backgrounds` (para fundos) no `index.html` com os caminhos corretos.
