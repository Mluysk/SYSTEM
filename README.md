# Next Tech Website

Este repositório contém uma landing page moderna para a Next Tech, com foco em transmitir inovação, elegância e tecnologia.

## Como visualizar

Basta abrir o arquivo [`index.html`](index.html) em qualquer navegador moderno. Para obter a melhor experiência, utilize a folha de estilos [`styles.css`](styles.css) e os scripts [`script.js`](script.js) incluídos na mesma pasta.

## Tecnologias e recursos

- HTML semântico estruturado em seções (hero, serviços, cases, insights e contato).
- Design responsivo com gradientes, efeito glassmorphism e animações suaves em CSS.
- JavaScript leve para interações: rolagem suave, botão “voltar ao topo” e revelação progressiva de conteúdo.
- Tipografia moderna utilizando a fonte [Outfit](https://fonts.google.com/specimen/Outfit).

Sinta-se à vontade para adaptar os conteúdos e estilos conforme a identidade da sua marca.
